# Siva — Portfolio

A high-performance developer portfolio showcasing full-stack Java web applications, modern responsive UI, and interactive animations.

**Live site:** [https://YOUR-SITE-URL/](https://YOUR-SITE-URL/)

## Tech Stack
- **React 19**
- **Vite**
- **Tailwind CSS 4**
- **Framer Motion**
- **AOS (Animate On Scroll)**
- **EmailJS**
- **WebGL (Fluid Splash Cursor)**

## Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```

## Environment Variables
Create a `.env.local` file in the project root with your EmailJS credentials:

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```
